# FPRO AI LAB

Türkçe, sade Android uygulaması: GPT ve Claude ortak sohbet, yerel araştırma kayıtları ve API bütçe takibi.

## Durum
Android kaynak proje hazırlanmıştır; dosyaların depoya aktarımı henüz tamamlanmadı. APK derlenmedi veya test edilmedi.

## Güvenlik
API anahtarlarını GitHub deposuna veya kaynak koda eklemeyin. API maliyetleri için sağlayıcı tarafında da limit kullanın.

## Kaynak
İlk Android kaynak ZIP dosyası sohbet içinde paylaşılmıştır.
